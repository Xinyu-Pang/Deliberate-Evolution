# Deliberate Evolution: Agentic Reasoning for Sample-Efficient Symbolic Regression with LLMs

This repository contains the official implementation of our ICML 2026 paper:

> **Deliberate Evolution: Agentic Reasoning for Sample-Efficient Symbolic Regression with LLMs**

Deliberate Evolution is an agentic framework for sample-efficient symbolic regression with large language models.

Code, benchmarks, and reproduction instructions will be added soon.
